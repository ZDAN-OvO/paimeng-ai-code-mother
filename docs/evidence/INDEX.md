# 证据索引

每条承诺现在算不算数，看这里。`npm run check:docs` 读这张表，状态由脚本算，不手写。

- **通过** — 有交付证据，且「覆盖路径」里的文件自「记录 sha」之后没改过。
- **过期** — 证据还对应旧代码，覆盖的路径改过了。
- **未检** — 没有交付证据。未检不算失败，但也算不了数。

「覆盖路径」是逗号分隔的 glob，相对仓库根。「记录 sha」是录证据时的提交。
