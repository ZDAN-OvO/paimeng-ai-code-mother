## Requirement

核实三份设计文档与代码是否一致，并持续由 agent 维护；每个「修复」和「做成」、「错误」和「做不成」，都要有可以复现的证据。

范围包含 `docs/api.md` 与 `src/shared/api/`（前端与后端之间的实际契约），核对以静态对照为主，读代码判断不了的结论才起 dev server 实测。
