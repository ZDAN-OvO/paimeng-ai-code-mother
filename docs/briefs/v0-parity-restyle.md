# Brief: 把原型补到 v0 的形态基线（明暗主题、首页、对话页）

- Stage: execute
- Source: 用户要求：支持明/暗主题切换；首页与对话页风格向 v0 靠拢（附 v0 首页与对话页两张截图），首页要简短居中文字、支持语音输入、模板抽象改为「应用长相」且主输入框不出现模板；对话页要折叠生成中的 agent 回复、右栏改为用户自己点选单个面板、并补左侧边栏。

## Goal

- 服务于「界面形态定稿 → 后端按前端补接口」这个决定：形态确认后，接口契约不再因为版式反复。
- 把现有原型与 v0 的三处形态差距补齐：明暗主题、首页、对话页工作区。
- 让首页与对话页成为可以直接照此补接口的界面基线，而不是一次性草图。

## Context

- 现有原型在 `src/prototype/` 与 `src/app/prototype/`，尚未提交；三栏工作区、悬浮 MVP 清单、mock 数据存 localStorage。本次在它之上改造，不新建页面。
- v0 参照只有两张截图：首页是居中的「您想创建什么？」+ 单一输入框（模型、语音、发送）+ 提示词胶囊 + 下方模板画廊；对话页是左栏 + 折叠的过程消息 + 右栏单面板（`App Preview / Code` 与「+」菜单）。
- 本轮已确认：左栏照 v0 结构但只做有数据的分区，不含 Design Systems；模板 = 完整示例应用（结构 + 视觉），放首页画廊、点开预览后再建项目；右栏真做 6 个面板（预览、代码、版本 diff、日志、设置、产物），Database 与 Terminal 禁用并标「未接通」。
- 产品单用户本地优先、中文优先；`docs/mvp.md` 明确不做移动端 App、不做公开模板画廊。
- 13 条验收路径必须仍能演示；HUD 是原型工具，不属于产品界面。

## Materials

- 主参照：[v0 首页](assets/v0-home.png) 与 [v0 对话页](assets/v0-chat.png)，只以图中可见的结构、层级、间距与控件为准。
- 次参照：`src/prototype/` 现有实现与 `docs/mvp.md` 的 13 条路径；改造后每一条都要还能走通。
- 禁止引入 v0 的站点账号、图片、头像、英文文案与模板缩略图；截图之外的行为一律不猜，缺信息时留空并标注。
- 模板缩略图用现有 mock 站点渲染，不另外造素材。

## Boundaries

- 不改 `src/prototype/types.ts` 的字段语义与 `src/prototype/README.md` 的接口契约形状；新面板需要的字段只加不改名。
- 不搬 v0 的品牌、logo、英文界面文案与模板素材，界面保持中文。
- 不把原型做成生产实现：不新增后端、数据库、真实鉴权，数据仍在 localStorage。
- 不做移动端布局，也不改 `docs/mvp.md` 的 13 条范围。
- 不因视觉改造降低现有交互：折叠的过程消息仍可展开，版本 diff、回滚、发布仍可操作。

## Done

- 第一批交首页与对话页在明/暗两套主题下的 4 张截图，对话页需含「生成中全部折叠」与「右栏切换面板」两个状态。
- 方向确认后，主题与左栏/右栏规则覆盖发布页与技能页，并补一段录屏：首页建项目 → 对话页折叠 → 切换右栏 → 发布。
- `npm run lint`、`npx tsc --noEmit`、`npm run format:check`、`npm run build` 全绿，浏览器控制台无报错。
- 13 条演示路径逐条仍可走通；HUD 清单与重置仍可用。

## Assumptions

- 明暗默认跟随系统，顶栏提供切换并记住选择；只作用于产品界面，预览里的生成站点保持模板自己的明暗。
- 语音输入用浏览器 SpeechRecognition，不可用时按钮给出提示并保留文字输入，不接后端 ASR。
- 左栏可折叠，折叠后对话列占满；右栏宽度可拖，与左栏状态一起记住。
- HUD 保留，截图时临时隐藏或裁掉，避免干扰风格对比。
- Database 与 Terminal 只出现在右栏「+」菜单里，点击给出说明，不渲染假数据。
