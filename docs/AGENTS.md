# docs/

仓库级文档。

## 放置

- `architecture.md` 是唯一的架构总述。决策变了先改这里，再改受影响的 ADR。
- `mvp.md` 记范围、决策记录与里程碑，回答「做什么、为什么、什么时候」。实现怎么搭，看 `architecture.md`。
- `adr/` 每个文件只记一个不可逆或代价高的决策：背景、选项、结论、后果。编号递增，不删旧文件。
- 实现细节不写进文档。文档说明「为什么这样定」，代码说明「怎么做的」。

## 生命周期

- 架构文档是活文档，随 PR 更新；过期内容直接改，不叠加「补充说明」。
- ADR 一旦接受就不再改写结论；被推翻时新增一条并在旧条目顶部标注 superseded。
