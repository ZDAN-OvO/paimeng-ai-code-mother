# 依赖白名单与 registry 中继

生成的应用只能使用白名单内的 16 个直接依赖。检查覆盖全部依赖声明字段，拒绝 Git、tarball、本地路径、别名和 workspace 来源，锁文件只由平台生成。安装在独立的任务容器中进行，只挂载过滤后的 manifest，默认禁止安装脚本，并且只能通过后端的 registry 中继访问 npm；开发和构建容器完全没有出口。白名单限制的是依赖选择，并不等于审计过所有间接依赖的代码。

## Considered Options

- 允许任意依赖并依靠容器隔离：能力更大，但安装脚本和任意包会扩大攻击面，构建失败也更难修复。
- 预装依赖、完全禁止安装：最安全，但无法在静态和 Vue、React 之间切换，也不能按需增删依赖。
