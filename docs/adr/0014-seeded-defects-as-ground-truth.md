# 0014 评测基准靠预埋缺陷，不靠 LLM 判分

- 状态：已接受
- 日期：2026-11-09

## 背景

review agent 与主 agent 的提示词要靠评测来调，最终交给夜间循环自动调。如果「这条该不该打回」由另一个 LLM 判，调优会收敛到两个模型互相认同，而不是真的拦住问题。

可选做法：

1. LLM 判分：另一个模型读产物与转录，给出该不该通过。
2. 人工逐条标注。
3. 构造用例时预埋已知缺陷，并放入干净项目与需要 review 的大改动，预期走向写在用例里。

## 结论

选 3。每条用例写明初始项目、本轮目标、预埋内容与预期走向；拦截率、误打回率、漏审率都按用例里的预期计算，不需要模型判断。人工只做抽检校准。

## 后果

- 构造用例的成本高于让 LLM 判分，用例要随契约更新维护，过期的用例不再计分。
- 只能衡量预埋得到的问题；视觉质量、需求理解这类难以预埋的问题，靠人工抽检与交付后的返工率观察。
- 用例集必须包含干净项目，否则误打回率算不出来。
