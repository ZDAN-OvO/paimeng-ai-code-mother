# 0005 发布：standalone 产物加通用 runner

日期：2026-11-06
状态：已接受

## 背景

目标是发布可运行的 full-stack 应用，静态导出不成立。每个应用构建独立镜像慢且吃磁盘。

## 选项

1. 静态导出。
2. 每个应用构建专属镜像。
3. 复用 `next build` 的 `.next/standalone`，用通用 runner 镜像挂载产物。

## 结论

选 3。发布等于复制产物、启动容器、网关按 `deployKey` 路由。

## 后果

- 不为每次发布做镜像构建，也不需要本地 registry。
- 产物目录与沙箱工作区分离，沙箱回收不影响已发布实例。
- 回滚是切换软链并重启容器，历史版本保留。
