# 0016 沙箱网络默认拒绝，必要访问经受控代理放行

日期：2026-11-10
状态：已接受（策略原则）；传输方式待验证后选择

生成项目需要安装依赖，也可能需要调用外部服务。永久关闭全部联网会阻断这些行为；普通 Docker 桥接又允许访问公网及宿主可达服务。因此保留默认拒绝直接出站，由宿主控制的代理按当前 Sandbox 的策略放行目标。模型与 Skill 不能自行扩大权限；允许依赖下载不授予 GitHub 同步或远端写入权限。

本地实验验证了禁网容器通过临时代理安装 registry 单包，也验证了 internal bridge 仍能访问宿主桥接地址。关闭容器间通信只能解决已测的横向访问，不能代替宿主边界。暂不把 internal bridge 直接定为默认，也不将修改宿主全局防火墙作为启动应用的隐含动作。

禁网加 Unix socket 与桥接加宿主访问控制都是候选：前者增加中继管理，后者需要证明宿主隔离、预览回包和其他项目兼容。选择须由这项验证驱动。允许列表的目标与地址校验、策略归属和访问记录属于生产实现；registry 单包成功不证明这些能力已经交付。当前结构与未决项见[架构第 8 节](../architecture.md#8-沙箱与预览)。
