# 0004 技能路由：描述常驻，正文按需加载

日期：2026-11-06
状态：已接受

## 背景

技能是带 frontmatter 的目录，与 Claude Code 同构。用户既能用内置技能，也能自建与导入。

## 选项

1. 全部正文常驻 system prompt。
2. 描述常驻，模型调用 `load_skill` 取正文。
3. 回合前用便宜模型预选技能。

## 结论

选 2。描述一行一条，全量列出，不设上限；正文、references、scripts 都按需取。

## 后果

- 路由判断由生成模型自己做，少一次调用，也能看到对话细节。
- 用户技能与内置技能同一套加载逻辑，只是在磁盘位置和信任状态上不同。
- 描述过多时会出现注意力稀释，先观察，不提前加预筛。
