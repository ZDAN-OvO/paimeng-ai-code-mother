THROWAWAY PROTOTYPE · 可丢弃原型

一个执行槽位，多个应用怎样排队？

验证问题：模型生成可以并发，但构建和沙箱命令只允许一个 Execution 占用槽位。同一次占用内复用容器与依赖；释放时销毁容器。取消、超时或进程重启后，能否确认旧环境已清理，再允许下一个应用执行？

本页是内存中的逻辑模拟，不连接 Docker、不测内存、不接产品数据库。真实 React / Vue 构建实验运行 npm run prototype:sandbox，结果可在页面下方载入。当前预览使用静态 Delivery，不占槽位。

    这次原型的边界

    只读依赖可以跨请求共用；可写源码、输出与临时目录不能跨 App 共用。成功不直接释放槽位，必须先销毁旧容器。

    跨进程锁、数据库持久恢复、磁盘配额、gVisor 隔离和真实平台接入尚未验证。这个页面不能证明容器安全。
